Now, we can see that variables ending with “_x”, “_y” or “_z” are highly correlated, so that in a regression model this might imply a multicollinearity problem. I decided to drop out those variables and leaving only 20 of them.

subsettrain <- subsettrain %>% select(-contains(c("_x", "_y", "_z")))
# subsettrain
dim(subsettrain)
## [1] 19622    20

This is the data set I am going to use to build a model. Now, we will use cross-validation using the caret package, and choose one of the following methods that I remember from the lecture notes and videos: “glm”, “lm” (not available since the classification is over 5 different types), “rf”, “svm”, “pca”. I chose “rf” since is the one we explore the most in the course and it was used for the data set “iris” to classify the species given the other predictor variables.
